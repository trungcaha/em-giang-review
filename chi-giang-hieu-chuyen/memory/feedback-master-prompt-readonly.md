Các file `muse-master-prompt.md` (vd giot-lanh-dau-goi/, ylee-sua-rua-mat/) là mẫu gốc để học cách viết. Không sửa, và prompt mới cho video khác KHÔNG đặt trùng tên `muse-master-prompt.md` — dùng tên riêng như `prompt-<chu-de>.md`.
**Why:** người dùng tưởng file gốc bị sửa khi thấy file mới trùng tên.
**How to apply:** đọc master prompt để học cấu trúc, ghi prompt mới ra file tên khác trong thư mục chủ đề. Nhân vật trong prompt không xưng "bác sĩ" (xem [[muse-studio-project]]).
